## NxtBar 1.4.0

### One less icon in the menu bar

The standalone gear is gone. Every host popover already had its own gear that
opens Settings for that machine, so a second icon was doing a subset of the same
job.

**Check for Updates** and **Quit** now live at the bottom of the Settings window,
next to the running version number, so you can read your exact build and update
from the same screen.

If you ever hide or drag away every host icon, the gear comes back on its own.
A menu bar app with nothing in the menu bar has no way to be reached or quit,
and that is not a state NxtBar will leave you in.
