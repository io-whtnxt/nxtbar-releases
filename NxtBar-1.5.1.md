# NxtBar 1.5.1

## Memory pressure bar

- The memory-pressure indicator is now an always-visible three-segment bar (green / yellow / red) on its own PRES row under RAM, with live swap usage and an OK / WARN / CRIT label — instead of a warning that only appeared once things were already bad.

## Machine removal in Settings

- Machines can now be removed from Settings: a − toolbar button (removes the selected machine) or right-click → "Remove …" on any machine in the list. Removing a machine also clears its stored auth token from the Keychain.
